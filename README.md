# ELECTRO1 — Tutor ZERO TO HERO

Repo de estudio con un tutor exigente en modalidad **ZERO TO HERO**: desde cero, sin saltos, justificando cada fórmula o idea antes de usarla.

## Cómo empezar

1. Leé el protocolo: [`tutor/PROTOCOLO.md`](tutor/PROTOCOLO.md)
2. Completá la entrada: [`tutor/ENTRADA.md`](tutor/ENTRADA.md)
3. Opcional: dejá material en [`tutor/inbox/`](tutor/inbox/)
4. Pedí el ejercicio o concepto concreto

## Qué hace el tutor

| Situación | Respuesta |
|-----------|-----------|
| Guía completa | Temas + orden (obligatorio / importante / si sobra tiempo) + empieza solo lo que pediste |
| Ejercicio puntual | Resolución completa con la estructura de 10 bloques |
| “No entiendo X” | Baja un nivel, ejemplo mínimo, y vuelve al problema |

## Estructura del repo

```
.cursor/rules/tutor-zero-to-hero.mdc   # regla siempre activa del tutor
tutor/
  PROTOCOLO.md                         # protocolo legible
  ENTRADA.md                           # plantilla de pedido
  PLANTILLA_GUIA.md                    # mapeo de guías
  PLANTILLA_RESOLUCION.md              # estructura de resolución
  inbox/                               # material crudo
  sesiones/                            # resoluciones guardadas
```

## Regla de oro

No se inventan enunciados ni datos. Si falta algo, el tutor pide solo lo mínimo y sigue.
